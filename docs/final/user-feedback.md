# 사용자 피드백과 개선 기록

[문서 전체 목차](README.md) · [서비스 소개·실행](../../README.md)

최초 정리 2026-10-24 · F03 수정 2026-10-30 · [제출 목차](README.md)

팀이 피드백·개선 항목으로 선정해 제공한 **사이트 주소, AI 질문 범위, 검수 표식의 의미, 활력 추천 결과, 비슷한 제품의 중복 추천**을 정리했다. 아래 확인 질문과 피드백 요약은 팀이 제공한 개선 주제를 정리한 것이며 실제 참여자 발언의 직접 인용이 아니다. 변경 내용은 코드·커밋·검증 기록을 근거로 작성했다.

기존 자료에서 팀이 전달한 테스트 날짜 분포는 **2026-10-22에 2건, 2026-10-23에 3건**이며 당시 제공 정보로 보존한다. 2026-10-30에 F03의 확인 질문을 교체했으며, 연결한 배지 제거 구현일은 **2026-10-29**다. 교체한 질문을 과거 날짜의 실제 발언으로 소급 확정하지 않는다. 현재 문서에는 개선 항목만 정리하며 참여자 등록 표는 두지 않는다. 개발자 QA는 실사용자 수에 포함하지 않는다. 공개 문서에는 팀이 정리한 질문·피드백 요약·개선 내용과 변경 근거를 싣는다. 2026-10-29에 중복 문서를 통합했으며, 이 문서가 현재 피드백의 기준이다. 다른 날짜·참여자 설명이 있던 [이전 작성본](../archive/user-feedback-2026-10-24.md)은 과거 기록으로 보존했다.

‘체감할 변화’는 개선으로 기대하는 사용상 효과다. 사용자 재평가로 측정한 만족도·시간 단축률은 아니다. F04는 개인에게 B군이 반드시 필요하다는 판단이 아니라 제품 탐색 목적 분류 개선이다. F05의 포장 변형 중복과 기존 섭취 제품의 성분 중복 검사는 별개의 기능이다.

F03 질문의 ‘검수완료’는 당시 제품 카드의 **‘표시 검수’ 배지**를 가리키는 팀 제공 질문 문구다. 제품 정보의 자체 대조를 나타내던 표식이며 공식 인증·제품 안전성 승인이라는 뜻은 아니다. 조준수가 기능 변경을 작성했고 `sayknow`가 PR #15를 canary에 병합했다. 이번 문서 수정의 작성자와 기능 구현 기여는 구분한다.

## 현재 증거로 말할 수 있는 범위

- F01·F02·F04·F05는 기존 운영 기준 `0bc17dc`의 변경·검증 기록에 연결한다. F03은 2026-10-29 PR #15의 canary 구현이며 이 문서 수정으로 새 운영 배포가 이루어졌다고 주장하지 않는다.
- 공식 표시 기반 후보 개선과 F03의 카드 배지 제거는 실제 커밋·코드에서 확인한다. 기능별 과거 검증 범위는 [검증 결과](test-results.md)를 따른다.
- 테스트 날짜·질문·요약은 팀이 제공한 내용을 반영했다. 개별 사용자의 직접 발언이나 측정하지 않은 개선 효과를 새로 만들어 넣지 않는다.
- 개인정보 때문에 핵심 피드백내용만 취합하여 반영함

## 추가 의견을 기록할 때

실제 사용 날짜·질문·응답 요약·반영 여부·이유·커밋/PR·재확인 결과를 구분한다. 공개 문서는 피드백 요약과 개선 기록 중심으로 관리하며 개별 응답 자료의 추가 제출·연결을 요구하지 않는다. 이름·연락처·개인 건강정보는 문서에 적지 않는다. 최소 5명의 실사용자 테스트라는 과제 요건은 유지하며 개발자 QA와 구분한다. 기술 검증 원본과 날짜별 성공/실패 범위는 [검증 결과](test-results.md)에서 관리한다.
