# 사용자 피드백과 개선 기록

[문서 전체 목차](README.md) · [서비스 소개·실행](../../README.md)

2026-10-24 · [제출 목차](README.md)

팀이 피드백·개선 항목으로 선정해 제공한 **사이트 주소, AI 질문 범위, AI 첫 질문 오류, 활력 추천 결과, 비슷한 제품의 중복 추천**을 정리했다. 아래 확인 질문과 피드백 요약은 팀이 제공한 개선 주제를 정리한 것이며 실제 참여자 발언의 직접 인용이 아니다. 변경 내용은 코드·커밋·운영 검증을 근거로 작성했다.

팀이 전달한 테스트 날짜 분포는 **2026-10-22에 2건, 2026-10-23에 3건**이다. 현재 문서에는 개선 항목만 정리하며 참여자 등록 표는 두지 않는다. 실제 참여자별 응답 원본과의 연결은 별도 확인 대상이고 개발자 QA는 실사용자 수에 포함하지 않는다. 2026-10-29에 중복 문서를 통합했으며, 이 문서가 현재 피드백의 기준이다. 다른 날짜·참여자 설명이 있던 [이전 작성본](../archive/user-feedback-2026-10-24.md)은 과거 기록으로 보존했다.

## 선정한 5개 개선 항목

| 항목 | 개선 요구사항 | 개선 전 → 개선 후 | 사용자가 체감할 변화 | 실제 변경·확인 근거 |
|---|---|---|---|---|
| F01 사이트 주소 | 사이트 주소가 직관적으로 안 와 닿아요 | `m2-1-itfc.onrender.com` → `vitastep-guide.onrender.com` | 영양제 안내 서비스라는 인상을 주고 다시 찾거나 공유할 때 식별하기 쉬움 | [주소 변경1e44b76](https://github.com/sayknow/M2-1/commit/1e44b76), [운영 URL](https://vitastep-guide.onrender.com/) |
| F02 AI 질문 범위 | 제품 정보말고 다른 영양제 질문도 알고싶어요 | 제품 표시 검색 중심 → 공식 일반 영양 지식과 표시 검색을 구분하는 상담 안내 | 제품을 선택하기 전에도 일반 영양 정보를 묻고 출처를 확인할 수 있음 | [상담 개선b1185bf](https://github.com/sayknow/M2-1/commit/b1185bf), [AI 설계](ai-design.md) |
| F03 AI 첫 질문 오류 | 첫질문에 오류때문에 진행이 이상해요 | 상품 근거만 찾다가 `AI_NO_EVIDENCE` → 제품 선택 없이 표시 읽기 안내 검색·인용 | 첫 질문에서 용어 설명을 바로 받고 질문을 시작할 수 있음 | [수정c8fa914](https://github.com/sayknow/M2-1/commit/c8fa914), [운영 M03 3/3](evidence/acceptance-api.json) |
| F04 활력 추천 결과 | 일상의 활력을 선택했는데 너무 많은 내용 때문에 오히려 복잡해요 | 넓은 성분 연결 → B 중심 직접 목적 후보와 관련 성분을 분리, 표시상 근거 제시 | 선택한 관심과 후보 이유의 연결을 이해하기 쉬움 | [분류b75f847](https://github.com/sayknow/M2-1/commit/b75f847), [PR #4](https://github.com/sayknow/M2-1/pull/4), 운영 대표 사례2/3 |
| F05 비슷한 제품 중복 추천 | 너무 비슷한 것들이 다 추천되니 오히려 선택이 힘들어요 | 비슷한 변형을 나열 → 표시 성분·제형·섭취법 기준 제품군을 묶어 대표 후보, 미충족 목적 우선 | 같은 종류를 반복해서 읽는 부담이 줄고 후보 간 차이를 살펴보기 쉬움 | [분류b75f847](https://github.com/sayknow/M2-1/commit/b75f847), [정책 상세](../recommendation-policy-v2.md), [정책 코드](../../backend/policy.py) |

‘체감할 변화’는 개선으로 기대하는 사용상 효과다. 사용자 재평가로 측정한 만족도·시간 단축률은 아니다. F04는 개인에게 B군이 반드시 필요하다는 판단이 아니라 제품 탐색 목적 분류 개선이다. F05의 포장 변형 중복과 기존 섭취 제품의 성분 중복 검사는 별개의 기능이다.

## 현재 증거로 말할 수 있는 범위

- 위 다섯 변경은 실제 코드/배포에 반영되었다. 운영 배포 기준은 `0bc17dc`다.
- 공식 표시를 근거로 추천 후보를 바꾸고 첫 질문을 실제 GPT로 확인한 기술 기록이 있다.
- 테스트 날짜와 요약은 팀 제공 정보를 반영했다. 실제 참여자의 발언·개선 후 평가는 응답 원본과 대조해야 한다.
- 개인정보 때문에 핵심 피드백내용만 취합하여 반영함

## 개선 결과를 확인하는 방법

아래는 개발자 재현 절차다. 실제 참여자의 재평가나 이번 정리에서 수행한 새 운영 검사로 세지 않는다. 실제 AI 요청은 사용량을 소비한다.

| 항목 | 확인 절차 | 기대 결과 |
|---|---|---|
| F01 | 운영 주소로 홈 열기 | `vitastep-guide.onrender.com`에서 영양제 첫걸음 소개 표시 |
| F02 | 제품 미선택 AI 대화에서 일반 영양 질문 입력 | 공식 지식 근거와 답변, 제품 근거와 구분된 출처 |
| F03 | 시작 질문 ‘함량과 기준량의 차이가 궁금해요’ 선택 | 제품 선택 없이 설명·공식 안내 출처, 검색 결과 없음이 곧 서버 장애가 되지 않음 |
| F04 | 일상의 활력·기존 없음·주의 해당 없음·5,000원 이하로 설문 | B 중심 직접 목적 후보 최대 3개와 표시 근거. 대표 API 기록은 2/3 성공 |
| F05 | F04 조건의 후보 목록·제품군 확인 | 표시·제형·섭취법이 같은 포장 변형은 대표 1개, 부족한 수를 관련 제품으로 채우지 않음 |

## 추가 의견을 기록할 때

실제 사용 날짜·질문·응답 요약·반영 여부·이유·커밋/PR·재확인 결과를 구분한다. 확인하지 못한 연령·발언·응답 보관 여부는 작성하지 않는다. 건강정보·이름·연락처를 제거한 원본을 확보한 뒤 이 문서에 연결한다. 기술 검증 원본과 날짜별 성공/실패 범위는 [검증 결과](test-results.md)에서 관리한다.
